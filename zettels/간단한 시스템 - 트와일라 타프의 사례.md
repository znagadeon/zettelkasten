# 간단한 시스템 - 트와일라 타프의 사례

상자를 이용해 간단한 생산성 시스템을 구축하는 사례. 트와일라 타프는 상자에 이름을 적고 목표를 작성해 넣는 것만으로 PARA 시스템의 Project 혹은 Area와 비슷한 시스템을 구축해냈다.

상자는 관리하기 간편하고, 넣을 수만 있다면 모든 종류의 자료를 모을 수 있으며, 눈에 보인다는 특징이 있는데 이 부분이 PARA 시스템의 장점과 연결된다.

중요한 것은 각 상자마다 이루고 싶은 목표를 적어 넣는 것인데 이 부분은 Jira의 Acceptance Criteria 혹은 OKR의 Key Result와 닮아 있다.
